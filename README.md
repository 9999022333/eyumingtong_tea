# 俄域茗通 · 官方网站

## 项目介绍
「俄域茗通」是一个专注于安徽茶文化中俄跨文化传播的品牌服务平台，
致力于将中国茶文化以符合俄罗斯本土审美的方式进行文化转译与推广。

本项目为品牌官方展示网站，作为 2026 年挑战杯参赛作品开发。

## 功能特性
- 品牌理念与服务介绍
- 茶文化内容展示
- 交互动画与视觉呈现
- 中俄跨文化传播业务说明

## 技术栈
- HTML / CSS / JavaScript
- 纯前端静态页面，无需后端服务

## 参赛信息
- 赛事：2026 年挑战杯
- 类别：文化创意和区域合作
- 项目：跨文化传播视域下文化转译服务的设计与运营

直接用浏览器打开 index.html 即可运行
